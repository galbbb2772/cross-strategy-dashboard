# Cross Strategy Dashboard

Public dashboard for the cross-family strategy research program.

## Views

- **Historical Top10:** selectable Top10 rankings with stock-style NAV curves.
- **Forward OOS:** official post-freeze BOX FWD-01 through FWD-06 paper Forward feed.
- **304 Strategy Registry:** searchable base-structure table with Strict/Phase evidence.

Historical source is a public-safe snapshot derived from `galbbb2772/cross-family-portfolio-lab`.
Forward uses the latest available public BOX Forward feed with a local canonical snapshot fallback.

The dashboard intentionally keeps historical research and prospective Forward OOS separate.


Current V2 phase coverage: 169/304 base structures classified; 84 strict-1x PASS, 85 financing-required. Weight-grid phase coverage: 3,271/7,696 scenarios.
